# Tech On Cue Labs

Free, tested companion files for the hands-on tutorials on the **[Tech On Cue YouTube channel](https://www.youtube.com/channel/UCYnWp5vA7ct5titSgEcIzng)**: AI tools and self-hosted apps, explained and installed step by step.

**[labs](https://github.com/techoncue-labs/labs)**: one folder per tutorial. Each has the exact commands from the video, the compose files, sample data to follow along with, tips and troubleshooting, and the version it was tested with.

Spotted an outdated step? [Open an issue](https://github.com/techoncue-labs/labs/issues). Contact: info@techoncue.app

*Not affiliated with the authors of the tools covered. Each tool keeps its own licence.*
